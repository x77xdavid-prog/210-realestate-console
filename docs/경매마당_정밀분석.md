# 경매마당(madangs.com) 정밀 분석 — 우리 사이트 업그레이드용

목표: 병원을 *지을 수 있거나 개원할 수 있는* 상가·토지·(병원 신축 가능) 빌라 위치를
**자세히·빠르게·쉽게** 검색. 마당의 기능을 분해해 우리가 채택할 것/버릴 것을 정한다.

분석일: 2026-06-16 (공개 검색 페이지 직접 확인 + 사용자 제공 상세 화면 캡처)

## 1. 마당 기능 전수 (검색 → 목록 → 상세)

### 검색 필터 (`/search`)
- 지역·법원: **지역별 / 법원별** 전환, 전국 17개 시도
- 용도: 주거용건물 / 상업용건물 / 토지 (+세부 분류)
- 유찰횟수: 0 / 1 / 2 / 3 / 4 / 5회~
- 물건상태: 진행중 / 변경·연기 / 낙찰 / 취하·취소
- 특수권리 (선순위임차인·임차권등기 등)
- 감정가/최저가: **범위**
- 토지/건물 면적: **범위**
- 지분필터, 매각일 날짜
- 정렬: 조회수 높은 등
- **내 필터 저장** ("이 조건을 내 필터에 저장")
- 보관함(관심), 알림센터

### 목록 카드
- 썸네일 사진, 물건종류, 사건번호, 소재지, 토지/건물 면적(평)
- 감정가, **최저가 + 할인율%**(95%↓ 등), 매각일 **D-day**
- **해시태그**: #유찰N회 #재매각 #선순위임차인 #임차권등기
- 조회수(view), 그리드/리스트 토글, 페이지네이션

### 상세 페이지
- 기본내역: 경매구분·용도·토지·건물·감정가·최저가·보증금·청구액·개시결정·감정일·배당종기·매각일
- **현장 사진 17장 + 갤러리**, 카카오·네이버 지도
- **감정가 / 최저가 / 실거래 매매 / 실거래 전세** 4종 비교
- 권리: 유찰N · 선순위임차인 · 임차권등기 · 선순위가등기
- 당사자(채무자/채권자/가압류권자), 기일내역(매각기일별 가격 추이)
- 문서함: 매각기일공고문 · 매각물건명세서 · **감정평가서** · 등기부등본 · 전입세대열람원 · **건축물대장** · 세대평면도
- 분석: 예상배당표 · 수익률분석
- 보관 · 인쇄 · 공유

## 3. 채택 우선순위 (우리 로드맵 매핑)

- **A 완료**: 병원 적합도 배지·필터 + 수집 전체 카드 그리드·페이지네이션
- **A2 (다음, 쉬움)**: 감정가·최저가·유찰·매각기일을 **구조화 필드**로 → 카드/필터에 **할인율%·D-day·유찰·진행중** + "반값" 테마. 가격/면적 **범위 필터**.
- **B (상세 패널)**: 로드뷰/위성 임베드 + 매물 핀 지도 + **실거래 매매/전세 비교** + 🏥 경쟁 의원·약국·체크리스트 강조 + 문서(감정평가서·건축물대장) 링크
- **C (검증 먼저)**: 현장 사진 갤러리(법원/온비드 상세 추출) + 권리 태그(선순위임차인·임차권등기). 안 되면 로드뷰로 대체.

## 4. 버릴 것 (병원 검색과 무관)

## 4b. 로그인 분석 (GStack 브라우저, 2026-06-16)

- **현장 사진의 정체**: 상세 사진 17장 = `cdn.madangs.com/img/{물건관리번호}{001~017}.jpg`.
  → 마당이 **법원 감정평가/현황조사 사진**을 자기 CDN에 재호스팅한 것. 원본은 courtauction.go.kr 물건 상세.
  **우리도 court 상세에서 직접 추출 가능** (C단계 실현성 확인됨, court 상세 스크래핑 필요).
- **요금(멤버십, (주)위시드)**: 월 정기구독 **32,900원**(정가 55,000), 연간 12개월 **289,000원**(월 24,084 환산, 정가 660,000), **7일 무료 체험**(정기구독 최초 1회).
- **유료(M) 게이팅 항목**: 전입세대열람원·건축물대장·예상배당표·수익률분석·입찰가분석·조회수분석.
- **기본(무료) 항목**: 사진보기·감정평가서·등기부등본·매각물건명세서·현황조사.
- **전략 포인트**: 마당이 **유료로 막는 건축물대장을 우리는 무료 공공데이터로 이미 제공**(verify_address). 여기에 병원 특화(심평원 경쟁의원·체크리스트)를 얹으면 "병원 특화 + 무료"로 확실히 차별화.

## 4c. 핵심 4개 게시판 정밀 (경매·공매·지도검색·경매통계, 로그인)

### 경매검색 `/search`
지역·법원 / 용도(주거·상업·토지+세부) / 유찰0~5+ / 물건상태(진행·변경·낙찰·취하) / 특수권리 / 감정가·최저가 범위 / 토지·건물면적 범위 / 지분 / 매각일 / 정렬 / **내 필터 저장**. 카드: 썸네일·할인율%·D-day·해시태그·조회수.

### 공매검색 `/search/gongmae`
경매와 동일 + **매각/재산형태**(압류재산·국유재산·신탁 등). 카드 태그: `공매 압류재산`, `공매(임대) 국유재산`, #지분매각, #일괄입찰. → 우리 온비드 수집(압류·국유·유입·수탁·기타)과 일치. **우리는 이미 보유**.

### 지도검색 `/mapsearch`
**Kakao 지도** + **지역명·지하철역명 검색(역세권)** + 상태 토글(진행·예정·변경·**공매**·낙찰·**재개발**·지분). 마커 클릭→물건. → 우리 B단계 지도는 여기에 **🏥 주변 경쟁 의원·약국 오버레이(심평원)** 를 더하면 마당보다 우위. (Kakao 지도 JS 키 무료)

### 경매통계 `/statistics`
기간(3·6·12개월) / 법원·지역 / 용도 필터. 지표: 총 물건수, 낙찰 물건수, **평균 매각률 20.45%**, **평균 매각가율 61.41%**, 평균 응찰자 수, 감정가·매각가 총액. 차트: 월별 추이, 매각가율 구간 분포, 용도별·법원별.
→ ⚠️ **우리는 진행 중 물건만 수집**하고 **낙찰(매각결과) 이력은 미수집** → 통계는 별도 데이터(매각결과 수집 or 통계 API) 필요. **우선순위 낮음**(분석가용, 병원 검색에 부차적).

**4개 게시판 우리 적용 우선순위:** 경매·공매(이미 보유) → 지도검색(B단계, 경쟁의원 오버레이로 차별화) → 경매통계(데이터 부담 커서 후순위).

## 5. 핵심 인사이트
- 마당의 강점은 **세분 필터 + 카드 한눈에(할인율·D-day·태그) + 사진/지도/문서가 한 상세에 집약**.
- 우리는 여기에 **병원 특화(심평원 경쟁의원·체크리스트·용도지역 병원 가능 판정)** 를 얹어 *경매 사이트엔 없는 가치*를 만든다.
- 데이터는 대부분 **이미 수집 중인 값(감정·최저·유찰·기일)** 으로 가능. 사진·권리만 상세 추출 검증 필요.
