# 병원(정형외과) 건물 매입·신축 체크리스트

> 작성일: 2026-06-12
> 대상: 정형외과 의원/병원 개원·이전을 위한 건물 매입 또는 토지 매입 후 신축
> 🔎 표시 = 본 프로젝트의 매물 자동 검색 도구(공공데이터 검증)로 자동 확인 가능한 항목
>   (건축물대장 `building_ledger.py`, 토지이용계획 `land_info.py`, 실거래가 `market_price.py`)

---

## 0. 가장 먼저 결정할 것 (모든 검토의 출발점)

- [ ] **의원급 vs 병원급 결정** — 30병상 미만 의원인지, 30병상 이상 병원인지에 따라 건축물 용도가 완전히 달라짐
  - 의원(입원실 없거나 소규모): **제1종 근린생활시설** → 대부분의 상업·주거지역에서 가능
  - 병원(30병상 이상, 요양병원 등): **의료시설** → 용도지역 제한이 훨씬 까다로움 (전용주거지역 등 불가)
- [ ] 목표 규모 확정: 연면적, 층수, 진료과 구성(영상의학 장비, 물리치료실, 도수치료실, 수술실, 입원실 유무)
- [ ] MRI/CT 도입 계획 — 도입 여부에 따라 건물 구조·전기·층고 요구사항이 크게 달라짐 (아래 4장)
- [ ] 총예산 상한선: 매입(또는 토지+공사비) + 취득세 + 인테리어 + 장비 + 운영자금 6개월분

---

## 1. 입지 분석 (매입·신축 공통)

- [ ] **배후 인구**: 반경 1~3km 인구수, 특히 **50대 이상 비율** (정형외과 주 수요층)
- [ ] 반경 1km 내 경쟁 정형외과·재활의학과·통증의학과 수와 규모
- [ ] 대중교통 접근성: 버스정류장·지하철역 도보 5분 이내 여부
- [ ] **주차장**: 정형외과는 차량 내원 비율이 높음(거동 불편 환자·고령자) — 법정 대수보다 여유 있게
- [ ] 가시성: 간판 노출(대로변, 코너), 차량 진입 동선
- [ ] 보행 접근: 출입구 무단차, 경사로 설치 가능 여부 (목발·휠체어 환자)
- [ ] 주변 개발 호재/악재: 재개발·재건축 계획, 신규 대형병원 입점 예정 여부
- [ ] 처방 연계: 인근 약국 유무(없으면 약국 유치 가능 공간 확보가 임대수익+환자 편의에 유리)

## 2. 법규 검토 (계약 전 필수)

- [ ] 🔎 **용도지역·지구 확인** (토지이용계획확인원) — 의료시설/근린생활시설 건축(용도변경) 가능 여부
- [ ] 🔎 **건축물대장 확인**: 현재 용도, **위반건축물 여부**, 구조, 사용승인일, 승강기 유무
- [ ] 현재 용도가 의원 용도가 아니면 **용도변경 가능 여부**와 비용 — 주차장 추가 확보 요구가 걸림돌이 되는 경우 많음
- [ ] **부설주차장 설치 기준** (지자체 조례 확인): 의료시설/근생 면적당 법정 주차대수 충족 여부 — 용도변경 시 추가 주차 요구로 무산되는 사례 빈번
- [ ] **장애인등편의법**: 의원은 바닥면적 100㎡ 이상이면 장애인 편의시설(경사로, 장애인화장실, 점자블록 등) 의무 — 기존 건물에 설치 가능한지
- [ ] **소방·피난 규정**: 스프링클러(6층 이상 등), 피난계단, 방화구획 — 노후 건물은 보강 비용 큼
- [ ] **승강기**: 2층 이상 개원 시 사실상 필수(법적으론 6층 이상 의무) — 침대·휠체어가 들어가는 규격(병원용)인지
- [ ] 의료법 시설기준 충족 가능 여부 (진료실·처치실·방사선실 등 면적, 입원실 두는 경우 기준 강화)
- [ ] 의료기관 개설 절차 확인: 의원 = 보건소 **개설신고**, 병원급 = 시·도지사 **개설허가** (허가는 기간·요건 추가)

## 3. 권리 분석 (매입 시)

- [ ] **등기부등본**: 근저당·가압류·가처분·전세권 등 권리관계, 채권최고액이 매매가 대비 과도하지 않은지
- [ ] 토지·건물 **소유자 일치** 여부, 공유지분 여부 (공유면 전원 동의 필요)
- [ ] **임차인 현황**: 기존 임차인 명도 일정·비용, 상가임대차보호법상 계약갱신요구권(최대 10년)·권리금 분쟁 리스크
- [ ] 🔎 **실거래가 비교**: 주변 유사 건물 실거래가 대비 적정가 여부
- [ ] 경매·공매(온비드) 물건인 경우: 말소기준권리, 인수되는 권리, 명도 난이도 확인
- [ ] 계약서 특약: **부가가치세 처리** 명시 — ⚠️ 의료업은 면세사업이라 건물분 부가세 **환급 불가**, 부가세 별도인지 포함인지에 따라 실부담 수억 차이 가능

## 4. 건물 물리 조건 — 정형외과 특화 (가장 자주 놓치는 부분)

- [ ] **층고**: 천장 매립 장비·덕트 감안 유효 천장고 2.7m 이상 (신축이면 층고 3.6m 이상 권장)
- [ ] **바닥 하중**: MRI는 본체만 3~5톤 이상 — 구조안전진단으로 보강 필요 여부 확인, 1층 또는 지하 배치가 일반적
- [ ] **MRI 반입 경로**: 벽체 개구·크레인 반입 가능 여부, 차폐실(RF shield) 설치 공간, 퀜치 배관(초전도형) 경로
- [ ] **방사선 차폐**: X-ray·C-arm실 납 차폐 시공 가능 여부 (진단용 방사선 발생장치 설치 신고·검사 통과 필요)
- [ ] **전기 용량**: MRI/CT 도입 시 수전용량 증설(별도 변압기) 가능 여부, 비상전원
- [ ] **급배수**: 물리치료실·처치실 배관 추가 가능 여부, 층간 배관 이동 제약
- [ ] **기둥 간격(스팬)**: 물리치료실·운동치료실은 넓은 무주(無柱) 공간이 유리
- [ ] 냉난방 방식과 환기(의료기관 환기 기준), 외벽 간판 설치 가능 면적
- [ ] 노후 건물이면: 누수·균열·결로 이력, 리모델링 총비용 견적을 **계약 전에** 받아볼 것

## 5. 재무 검토

- [ ] 총사업비 산출: 매입가(또는 토지+공사비) + **취득세**(매입 약 4.6%, 신축 원시취득 약 3.16%) + 중개수수료 + 설계·감리비 + 인테리어 + 의료장비 + 예비비 10%
- [ ] 대출 계획: 담보대출 LTV, 의사 신용대출(메디컬론), 금리·거치기간 — 신축은 **공사 중 이자(브릿지)** 별도 계산
- [ ] **명의 구조 결정**: 개인(원장) 명의 vs 배우자·가족 명의 후 임대 vs 별도 법인 — 소득세·상속증여·건보료 영향, 세무사 사전 상담 필수
- [ ] 의료업 면세사업자이므로 부가세 환급 불가를 전제로 한 자금 계획 (3장 참조)
- [ ] 보유 단계 세금: 재산세, (해당 시) 종합부동산세, 임대수익 발생 시 소득 구조
- [ ] 출구 전략: 향후 매각·임대 가능성 — 의료 특화 인테리어는 범용성이 낮아 매각가에 불리할 수 있음

## 6. 신축 추가 체크 (토지 매입 → 신축)

- [ ] 🔎 토지 용도지역의 **건폐율·용적률** — 목표 연면적이 나오는지 가설계(볼륨 체크) 먼저
- [ ] **도로 접면**: 폭 4m 이상 도로에 2m 이상 접해야 건축 가능, 막다른 도로·현황도로 여부
- [ ] 일조권 사선제한·고도지구·지구단위계획 등 형태 제한
- [ ] 법정 주차대수 충족 가능한 대지 형상인지 (지하주차장 필요 시 공사비 급증)
- [ ] 지반: 지질조사 결과, 연약지반·암반 여부 (파일·발파 비용), 인접 건물 민원 리스크
- [ ] 상수·하수·전기·도시가스 인입 여부와 비용
- [ ] **의료시설 설계 경험 있는 건축사** 선정 — 방사선실·차폐·환자 동선은 일반 설계와 다름
- [ ] 시공사 선정: 의료시설 시공 실적, 하자보수 조건, 계약 방식(도급 총액 vs 실비정산)
- [ ] **일정 리스크**: 설계~건축허가~착공~사용승인~개설신고까지 통상 18~30개월 — 개원 목표일 역산, 지연 시 임시 진료 공간 계획
- [ ] 사용승인 후 의료기관 개설신고·방사선장치 검사·소방완비 등 인허가 순서 정리

## 6.5 철거 후 신축 (기존 건물 매입 → 철거 → 신축)

> 건물이 있는 매물이라도 **부수고 새로 짓는 전제**라면 건물 상태(층고·하중·승강기·노후도)는 무관하다.
> 핵심은 **토지 용도 · 도로 접면 · 입지** 3가지 — 이것만 좋으면 검토 가치 있음. 노후 건물은 오히려 매입가 협상에 유리.

- [ ] 🔎 **용도지역** — 신축할 의원/병원 용도가 허용되는지 (토지이용계획)
- [ ] 🔎 **도로 접면** — 폭 4m 이상 도로 접면 (맹지면 즉시 탈락), 차량 진입 동선
- [ ] 🔎 **신축 가능 볼륨** — 대지면적 × 용적률 = 최대 연면적이 목표 규모를 충족하는지
- [ ] 🔎 **토지 가치 기준 가격 검토** — 건물값은 0으로 보고 공시지가·주변 토지 실거래가 대비 매물가 평가
- [ ] **철거비 견적** — 석면 사전조사(의무)·해체공사 허가·폐기물 처리비, 연식 오래된 건물은 석면 처리비 변수 큼
- [ ] **임차인 전원 명도** — 철거 전제이므로 일부 명도 실패가 사업 전체를 막음 (매입보다 치명적), 명도 일정·비용을 계약 특약에
- [ ] 멸실등기 → 착공까지 일정이 전체 개원 일정에 반영됐는지 (철거 1~3개월 추가)
- [ ] 인접 건물 이격·민원 리스크 — 철거+신축 공사 소음·분진, 인접 건물 균열 분쟁 대비 (사전 안전진단)
- [ ] 취득세는 건물분 포함해 납부 후 철거 — 토지만 살 때보다 세부담 차이 확인
- [ ] 이후 절차는 6장(신축 체크) 동일 적용

## 7. 매입 vs 철거 후 신축 vs 신축 비교 판단 기준

| 항목 | 매입(리모델링) | 철거 후 신축 | 나대지 신축 |
|------|--------------|-------------|------------|
| 개원까지 기간 | 짧음 (3~9개월) | 가장 김 (철거 +1~3개월, 총 20~33개월) | 김 (18~30개월) |
| 초기 비용 예측 | 비교적 명확 (단, 노후건물 보강비 변수) | 철거비·명도비 변수 | 공사비 상승·지연 변수 큼 |
| 정형외과 최적화 | 제약 있음 (층고·하중·차폐) | 자유로움 | 자유로움 (MRI·동선 최적 설계) |
| 입지 선택폭 | 기존 건물 매물에 한정 | **넓음 — 건물 상태 무관, 입지만 보면 됨** | 나대지 매물이 드묾 |
| 권리 리스크 | 임차인 명도, 위반건축물 | **임차인 전원 명도 (치명)** | 인허가·민원·시공사 리스크 |
| 건물 검토 항목 | 전부 적용 | **생략 (용도·도로·입지만)** | 해당 없음 |

**판단 원칙**: MRI 등 중장비 도입 + 장기 운영(10년 이상) 계획이면 신축 계열 우위, 빠른 개원·이전이 목적이면 매입 우위. 좋은 입지에 나대지가 없으면 **철거 후 신축이 입지와 최적 설계를 동시에 잡는 현실적 대안**.

## 8. 계약 전 최종 점검 (Go / No-Go)

- [ ] 🔎 위반건축물 아님 + 용도(변경) 문제 없음 확인됨
- [ ] 주차장 법정 대수 충족 (용도변경 포함)
- [ ] MRI/X-ray 설치 가능 (하중·차폐·전기) 확인됨 — 장비업체 현장 실사 완료
- [ ] 부가세 처리·명도 조건이 계약서 특약에 명시됨
- [ ] 총사업비가 예산 상한 이내 + 예비비 10% 확보
- [ ] 세무사(명의·세금)·건축사(법규·구조)·장비업체(설치) 3자 사전 검토 완료
