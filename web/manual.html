210 Orthopedics · Property Console Manual

병원 건물 매입 콘솔, 이렇게 사용하세요

매물 자동 수집부터 조건 비교, 체크리스트 검토, 매입 비용 계산까지 — 대시보드의 모든 기능을 처음 쓰는 분도 따라 할 수 있도록 정리한 설명서입니다.

Overview

이 서비스는 무엇인가요

병원 건물 매입 후보를 찾기 위해 공공 매물 정보를 자동으로 수집하고, 설정한 조건과 비교해 맞는 매물만 골라 보여주는 검토 콘솔입니다. 신규 매물이 발견되면 Gmail로 알림 메일도 보내드립니다.

매물은 어디서 수집되나요

소스내용비고
온비드 공매 양천·강서·구로·영등포구의 압류·국유·수탁 재산 공매 물건 캠코 공식 데이터
법원경매 서울남부지방법원 관할(양천·강서·구로·영등포) 부동산 경매 감정가·최저가·입찰 기간 표시
LH 분양공고 서울 지역 토지·상가 공급 공고 (신축 부지 후보) 공고중·접수중 건만 수집
직접 등록 부동산 중개사무소에서 받은 매물을 서류와 함께 직접 입력 매물장에서 등록
💡

네이버 부동산은 공식 데이터 제공이 없어 자동 수집 대상이 아닙니다. 대신 매물마다 네이버 부동산을 해당 위치로 바로 여는 버튼을 제공해 주변 시세와 일반 매물을 함께 확인할 수 있습니다.

Getting Started

접속하기

  1. 안내받은 대시보드 주소를 브라우저(크롬 권장)에서 엽니다. 휴대폰에서도 열립니다.
  2. 아이디와 비밀번호를 묻는 창이 뜨면 — 아이디는 아무 값이나(또는 비워도) 되고, 비밀번호만 정확히 입력합니다.
  3. 로그인 후 첫 화면(현황)이 보이면 준비 완료입니다. 주소를 즐겨찾기에 추가해 두세요.
🔒

비밀번호는 보안을 위해 이 문서에 적지 않습니다. 별도로 전달받은 값을 사용하시고, 잊으셨다면 관리자에게 문의하세요.

Scan

신규 매물 스캔

  1. 오른쪽 위 ⌕ 신규 매물 스캔 버튼을 누릅니다.
  2. 수집은 화면 뒤에서(백그라운드) 진행됩니다. 소스가 많아 수십 초 걸릴 수 있습니다.
  3. 잠시 후 화면이 갱신되며, 새로 발견된 매물이 있으면 상단에 ★ 신규 매물 배너가 나타납니다.
  4. 배너의 신규만 보기를 누르면 신규 매물만 모아 볼 수 있습니다.
💡

스캔 결과는 약 10분 동안 재사용됩니다. 방금 스캔했다면 같은 결과가 보이는 것이 정상이고, 10분이 지난 뒤 다시 스캔하면 새로 수집합니다.

Acquisition Criteria

건물·토지 조건 설정

건물·토지 조건 설정 패널에서 병원에 필요한 최소 조건을 입력하면, 매물 보드의 ⛳ 필수조건 필터와 카드별 조건 판정에 바로 반영됩니다.

빠른 시작 — 프리셋

  • 기존 건물 프리셋: 대지 150평 · 연면적 600평 기준으로 건물 매입 조건을 채웁니다.
  • 신축용 토지 프리셋: 대지 150평 · 접도 6m 기준으로 토지 조건을 채웁니다.

입력 항목

구분항목
건물 매입 필수최소 대지, 최소 건평/연면적, 최소 층수, 최소 주차 대수, 엘리베이터(필수/우선/무관), 승인연도 하한
토지 신축 가능성허용 용도지역, 최소 접도 폭, 최대 건폐율, 최소 용적률, 필수 확인 항목
  • 면적은 ㎡와 평 중 어느 쪽을 입력해도 자동 환산됩니다.
  • 입력하면 즉시 자동 적용·저장되고, 조건 저장 버튼을 누르면 저장 시각이 표시되며 확정됩니다.
  • 기본값 버튼으로 언제든 처음 설정으로 되돌릴 수 있습니다.

카드에서 할 수 있는 일

  • 원본 매물 ↗ (출처 바로가기) — 매물이 올라온 사이트로 바로 이동합니다. 네이버·LH·직거래 매물은 해당 매물 페이지로 직접 열리고, 온비드·법원경매는 그 사이트들이 딥링크를 막아 포털로 이동합니다 (버튼에 마우스를 올리면 물건관리번호·사건번호가 표시되니 그 번호로 검색하세요). 출처에 따라 버튼 이름이 온비드 ↗ · LH 청약 ↗ · 네이버 매물 ↗ 등으로 바뀝니다.
  • 네이버 — 매물 주소 기준으로 네이버 부동산을 새 탭에서 엽니다 (시세·인근 매물 확인용).
  • 지도/토지 — 매물 위치를 내부 지도·토지 정보 패널로 엽니다.
  • 매물장 추가 — 본격 검토할 매물을 매물장으로 보냅니다.
  • ♥ 하트 — 관심 매물로 보관/해제. 관심 목록과 현황 카드에 바로 반영됩니다.
💡

공매·경매 매물은 보증금/월세 대신 감정가·최저입찰가·입찰 기간이 메모에 표시됩니다. 온비드 물건은 온비드 ↗ 버튼으로 onbid.co.kr을 연 뒤 물건관리번호로 검색하면 상세 정보를 볼 수 있습니다.

Property Ledger

매물장 · 직접 등록

매물장은 실제로 검토 중인 매물의 진행 상황을 관리하는 장부입니다. 보드에서 추가한 매물과 직접 등록한 매물이 모두 모입니다.

부동산에서 받은 매물 직접 등록

  1. 매물장의 📄 직접 등록 (부동산 서류) 버튼을 누릅니다.
  2. 매물명과 지번 주소(예: 서울 양천구 목동 917-9)는 필수입니다. 지번 주소가 정확해야 체크리스트 자동 검증이 동작합니다.
  3. 매매가·유형(건물/토지)·면적·층수·주차는 아는 만큼 입력합니다. 비워 두면 공공데이터 검증이 채워 주기도 합니다.
  4. 부동산에서 받은 PDF·사진 서류를 첨부할 수 있습니다 (여러 개 가능, 개당 최대 15MB).
  5. 메모에 부동산 연락처나 특이사항을 적고 매물장에 등록을 누릅니다.

진행 상태 관리

매물마다 상태를 골라 진행 단계를 표시합니다:

검토중 연락 완료 방문 예정 협상중 보류 계약 검토

  • 메모는 입력하면 자동 저장됩니다.
  • 받은 서류는 매물별로 보관되며 나중에 추가할 수도 있습니다.
  • ⇩ 매물장 CSV — 전체 매물장을 엑셀에서 열 수 있는 CSV 파일로 내려받습니다.
  • 체크리스트 검토 버튼으로 매물별 정밀 검토를 시작합니다. (다음 섹션)

Checklist Review

체크리스트 검토

병원 건물 매입·신축 체크리스트를 기준으로 매물을 정밀 검토합니다. 공공데이터로 확인 가능한 항목은 자동 판정하고, 현장 확인이 필요한 항목은 직접 체크합니다.

검토 프로필 3종

프로필언제 선택하나요
기존 건물 사용 (매입)건물을 사서 리모델링 후 그대로 쓰려는 경우
철거 후 신축건물 딸린 땅을 사서 허물고 새로 지으려는 경우
나대지 신축빈 땅을 사서 새로 지으려는 경우

프로필에 따라 검토 항목이 달라지므로, 매입 방식에 맞는 프로필을 먼저 고르세요.

자동 검증 실행

  1. 매물장에서 체크리스트 검토를 열고 프로필을 선택합니다.
  2. 자동 검증 실행을 누르면 6단계 검증이 진행됩니다.
  3. 완료되면 등급과 함께 추천 액션이 담긴 리포트가 자동 생성됩니다.

자동으로 판정되는 항목:

  • 용도지역 (병원 입지 가능 여부)
  • 도로 접면 (접도 폭)
  • 주차 대수 · 승강기 유무
  • 주변 실거래 시세 비교
  • 건물 노후도 (사용승인 연도)
  • 같은 동의 정형외과 경쟁 의원·약국 현황 (심평원 데이터 — 전문의원 수와 정형외과 진료 의원 수를 함께 표시)

📝 미확인 항목 직접 채우기 (수동 검증 입력)

API 키가 없거나 공공데이터에 값이 없어 ‘미확인’으로 남은 카드는, 리포트 화면의 📝 미확인 직접 채우기 버튼으로 여는 수동 검증 입력 페이지에서 부동산 제공 자료(투자제안서·브리핑 등)를 근거로 직접 채울 수 있습니다.

  • 물건 정보 입력 → 자동 작성 — 용도지역·준공연도·주차·승강기·연면적·주용도를 넣고 누르면 관련 카드(용도지역·노후도·주차·승강기·현재용도)가 한 번에 채워집니다.
  • 카드별 상태·근거 수정 — 시세·경쟁 의원처럼 외부 자료가 필요한 항목은 직접 입력합니다.
  • 수동 입력 값은 리포트에 제공 자료 배지로 표시되고, 자동 검증을 다시 돌려도 보존됩니다. 미확인으로 비워 저장하면 자동값으로 되돌아갑니다.

등급 읽는 법

  • A · B — 적극 검토 권장 / 양호
  • C · D — 보완 확인 필요 / 신중 검토
  • 부적합 — 치명 항목(예: 병원 용도 불가)이 하나라도 부적합이면 점수와 무관하게 즉시 부적합 처리

📊 리포트 탭에서 요약과 추천 액션을 보고, ☑ 항목 체크 탭에서 항목별로 직접 적합/부적합/보류를 표시하고 메모를 남길 수 있습니다. 수동 체크 결과도 등급에 반영됩니다.

사이드바 지도검색은 조건에 맞는 매물을 지도 위에 병원 적합도 색 핀으로 표시합니다 (🟢 개원 가능 🔵 신축 가능 🟡 확인 필요). 핀을 누르면 매물 요약이 뜹니다.

🗺️

지도는 키 없이 바로 표시됩니다(OpenStreetMap). 서버에 VWorld 키(VWORLD_API_KEY)가 있으면 한국형 지도로 자동 전환됩니다(키는 서버에만 두고 노출하지 않습니다). 핀은 좌표가 확인된 ‘조건 일치’ 매물에만 찍힙니다.

사용 방법

  1. 매물 카드를 클릭하거나, 지도 패널에서 지번 주소를 직접 검색합니다.
  2. 오른쪽 정보 패널에 주소·조건 판정·면적 등 매물 요약이 표시됩니다.
  3. 네이버 부동산 열기 — 매물 좌표 중심으로 네이버 부동산이 새 탭에서 열립니다.
  4. 매입 계산에 반영 — 매물 가격을 아래 매입 비용 계산기로 보냅니다.
ℹ️

네이버 부동산·지도는 보안 정책상 대시보드 화면 안에 직접 표시되지 않습니다. 그래서 버튼을 누르면 새 탭으로 열리는 방식입니다.

공공데이터 검증

공공데이터 검증 (건축물대장·용도지역·실거래가) 버튼을 누르면 지번 주소 하나로 다음을 한 번에 조회합니다:

  • 건축물대장 — 층수, 연면적, 주차, 승강기, 사용승인 연도, 건폐율/용적률
  • 토지정보 — 용도지역, 도로 접면, 개별공시지가
  • 실거래가 — 주변 상업·업무용 건물의 최근 거래 내역
  • 주변 의료기관 — 같은 동 정형외과 의원·약국 현황 (심평원)

조회된 값은 매물의 비어 있던 정보에 자동으로 채워져 조건 판정(❓확인 필요 → ✅/미달)과 체크리스트 정확도가 올라갑니다.

매입 비용 계산

매입가만 입력하면 끝이 아닙니다 — 취득세·중개보수·대출 이자까지 포함해 실제 필요한 자금을 추정합니다.

  1. 매입가, 자기자본(보유 현금), 인테리어·장비 예산을 입력합니다. 금액 칸은 자동으로 콤마와 한글 단위(억/만)가 표시됩니다.
  2. 취득세율·중개보수율·대출 금리·대출 기간은 기본값이 들어 있으며 필요시 조정합니다.
  3. 아래 결과에서 총 매입 비용, 부족 자금(대출 필요액), 월 상환액(원리금균등 가정)을 확인합니다.
  4. 자기자본이 크게 부족하면 경고가 표시됩니다.
⚠️

계산 결과는 설정값 기반 추정치입니다. 취득세는 물건 종류·금액 구간·법령에 따라 달라지므로, 실제 매입 전에 반드시 은행 한도 조회와 세무사 검토를 거치세요.

Notification

Gmail 알림

스캔에서 신규 매물이 발견되면 설정된 Gmail 주소로 알림 메일이 자동 발송됩니다. 메일에는 매물 요약과 네이버 부동산·지도 바로가기 링크가 들어 있어, 휴대폰에서도 바로 확인할 수 있습니다.

받는 주소를 바꾸거나 추가하려면 관리자에게 요청하세요. (설정 파일의 notifiers 항목에서 변경합니다)

FAQ

자주 묻는 질문

스캔을 눌렀는데 매물 수가 바로 안 바뀌어요

수집은 화면 뒤에서 진행되어 수십 초 걸릴 수 있습니다. 잠시 기다린 뒤 새로고침(F5)해 보세요. 또한 결과는 약 10분간 재사용되므로, 방금 스캔한 직후라면 같은 숫자가 보이는 것이 정상입니다.

지도가 표시되지 않아요

사이드바 지도검색은 키 없이 OpenStreetMap으로 바로 표시됩니다 — 안 보이면 인터넷 연결을 확인하고 새로고침하세요. (서버에 VWorld 키가 있으면 한국형 지도로 전환됩니다.) 매물 상세의 네이버 지도 화면은 보안 정책상 대시보드 안에 직접 표시되지 않아 새 탭으로 열립니다.

‘원본 매물 ↗’을 눌렀더니 사이트가 안 열려요

실제 수집 매물(온비드·법원경매·LH·네이버)은 정상적으로 해당 사이트가 열립니다. example.test 같은 주소가 뜬다면 그 매물이 샘플(데모) 데이터라 가짜 주소를 가진 경우입니다. 온비드·법원경매는 그 사이트들이 직접 링크(딥링크)를 막아두어 포털로 이동하므로, 버튼에 마우스를 올리면 표시되는 물건관리번호·사건번호로 검색하면 됩니다.

매물이 너무 적게 / 너무 많이 보여요

기본 화면은 "조건 일치" 필터입니다. 수집 전체 칩을 누르면 모든 매물이 보입니다. 반대로 너무 많다면 ⛳ 필수조건 칩에서 조건 설정 패널의 기준으로 추린 결과를 보세요.

조건 판정이 "❓ 확인 필요"로 나와요

매물 정보에 주차 대수·승강기 등 판정에 필요한 값이 빠져 있는 경우입니다. 지도 패널에서 해당 매물의 공공데이터 검증을 실행하면 건축물대장 값이 자동으로 채워져 판정이 갱신됩니다.

체크리스트 자동 검증이 동작하지 않아요

매물의 지번 주소(예: 서울 양천구 목동 917-9)가 정확해야 자동 검증이 동작합니다. 직접 등록한 매물이라면 주소를 지번 형식으로 수정해 보세요. 현재 건축물대장·토지·실거래 자동 검증은 양천구(목동·신정동·신월동)·관악구(봉천동·신림동·남현동) 주소를 지원하며, 다른 지역은 관리자가 법정동코드를 추가하면 됩니다. (주변 의원·약국 조회는 동 이름만으로 전국 동작합니다.)

알림 메일이 오지 않아요

신규 매물이 없으면 메일도 발송되지 않습니다. 한 번 알림이 나간 매물은 다시 보내지 않습니다. 신규 매물이 분명히 있는데도 오지 않는다면 스팸함을 확인하고, 그래도 없으면 관리자에게 문의하세요.

비밀번호를 잊었어요

보안상 비밀번호는 문서에 기재하지 않습니다. 관리자에게 문의해 다시 안내받으세요.

실수로 "초기화"를 눌렀어요. 매물장이 사라지나요?

아니요. 초기화는 조건 설정과 계산기 입력값만 기본값으로 되돌립니다. 매물장·관심 매물·체크리스트 검토 기록은 서버에 저장되어 있어 지워지지 않습니다.

For Administrators

관리자 참고

운영·설정 변경은 아래만 기억하면 됩니다. 자세한 내용은 저장소의 README.md를 참고하세요.

  • 코드와 설정의 원본은 GitHub 저장소입니다. main 브랜치에 push하면 클라우드(Render)에 자동 배포됩니다.
  • 로컬 실행: python -m realestate_alert serve-web --config config.example.json --port 8765
  • 민감한 값은 모두 환경 변수로만 관리합니다 (코드·문서에 저장 금지): DASHBOARD_PASSWORD(접속 비밀번호), GMAIL_APP_PASSWORD(메일 발송), DATA_GO_KR_API_KEY(건축물대장·실거래가·온비드·LH·심평원), VWORLD_API_KEY(용도지역·도로접면·지오코딩)
  • API 키가 없으면 해당 소스만 건너뛰고 나머지 기능은 정상 동작합니다.
  • 수집 소스·알림 수신자·검색 조건은 config 파일(sources, notifiers, criteria)에서 변경합니다.
